# MusicOrganizer

本地音乐标签 / 歌词整理工具，双端：Android + Windows。

## 功能

- **曲库**：递归扫描（文件没变就不重读标签）、筛选、排序、搜索；搜索支持 `artist:xxx`、`size:>10m` 这类条件
- **批量标签**：多源查询后给出候选，逐字段显示「旧值 → 新值」，确认后才写入；写入后可按批次撤销
- **批量歌词 / 封面**：先列出候选与来源，确认后写入
- **整理**：按「歌手 / 专辑」生成移动计划（目标已存在同名文件则跳过），文件名查重，垃圾文件识别，标签文本清理
- **单文件编辑**：七个标签字段 + 封面（选择 / 移除 / 导出）+ 乱码编码修正
- **体检与 CSV**：统计缺项，导出曲库清单

## 使用提示

- 所有写入都先预览，确认后才动文件；写错了可在「撤销历史」里整批回退
- 网络默认直连；也可以选「自动」（跟随系统环境变量里的代理）或手填代理地址，设置页提供「测试连通」
- 曲库目录授权一次即可，下次启动自动恢复；授权失效会提示重新选择

## 平台

- **Android 7.0（API 24）及以上**：用系统文件选择器授权目录，只在授权的范围内读写
- **Windows 10 及以上**：直接读写所选文件夹，支持把文件夹拖进窗口切换曲库
